# Seyir için Homebrew

[Seyir](https://clay-tech.github.io/seyir/): Rust ile yazılmış, yapay zekâ kod ajanının her adımını canlı gösteren terminal.

```sh
brew install --cask clay-tech/seyir/seyir
```

Seyir kendini uygulamanın içinden günceller; `brew upgrade` gerekmez. Kaldırmak için `brew uninstall --cask seyir`,
ayarlar ve sohbetlerle birlikte silmek için `brew uninstall --zap --cask seyir`.

Cask, Seyir'in her sürümünden sonra otomatik güncellenir.
